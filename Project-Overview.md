# Secure Azure Landing Zone Lab

Hands-on Azure Landing Zone implementation using Microsoft Azure, focused on enterprise cloud foundation, governance, identity, networking and resource organization.

## 🎯 Objectives

- Design an enterprise-style Azure Landing Zone structure
- Implement Management Groups and subscription organization
- Separate Platform, Development, Production and Sandbox environments
- Implement Azure RBAC and least-privilege access
- Configure Resource Groups and resource organization
- Implement resource tagging and naming standards
- Design Azure Virtual Network and subnet segmentation
- Configure Network Security Groups
- Apply Azure governance and security best practices
- Validate the Landing Zone architecture and configuration
